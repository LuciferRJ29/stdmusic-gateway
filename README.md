# STD MUSIC Cloud Gateway (Vercel)

Dynamic API Gateway & Load Router for STD MUSIC Android App.

## How to Update Heroku URL Next Month:
1. Open this repository on GitHub or Vercel.
2. Edit `server.json` and `vercel.json` (or set `HEROKU_API_URL` environment variable on Vercel Dashboard).
3. Save / Commit.
4. Done! All STD MUSIC user apps automatically switch to the new Heroku backend.
